# VivahStyle promo (Remotion)

> Standalone Remotion project — NOT wired into the Next.js app's build. It has its
> own deps/bundler (Remotion fights Next). Develop with `npx remotion studio`.
> Three compositions: `PromoVertical` (1080×1920), `PromoLandscape` (1920×1080),
> `PromoSquare` (1080×1080). Render: `npx remotion render PromoVertical out/x.mp4`.
> Rendered videos land in `out/`. Brand tokens live in `src/theme.ts`.

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
